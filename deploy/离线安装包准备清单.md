# 内网离线安装包准备清单（联网机一次备齐）

目标：在无外网的公司服务器（海光 x86_64）上装好 Docker 并部署 V-FLO 智能办公系统。

## 一、目录结构

```
/opt/vflo-offline/
├── tgz/
│   ├── docker-27.x.tgz                 # Docker 静态二进制（推荐）
│   └── docker-compose-linux-x86_64     # Compose V2 插件
├── rpms/   （或 debs/，二选一）
│   └── docker-ce*.rpm + 依赖
├── images/
│   ├── vflo-base-images.tar.gz         # postgres/nginx/redis/python
│   └── vflo-app.tar.gz                 # 可选：已构建的应用镜像
└── offline-install.sh
```

## 二、下载地址（联网机）

| 项 | 获取方式 |
|----|----------|
| Docker 静态包 | `https://download.docker.com/linux/static/stable/x86_64/` |
| Compose V2 | `https://github.com/docker/compose/releases` 的 `docker-compose-linux-x86_64` |
| 基础镜像 | 见 `offline-install.sh prepare` 内说明（docker pull + save） |
| 应用依赖 | 本工程 `vflo-smart-office/` 整目录拷贝 |

## 三、步骤

```bash
# 联网机
cd /opt/vflo-offline
bash offline-install.sh prepare
tar czf vflo-offline-bundle.tar.gz vflo-offline/

# U 盘/内网传输到服务器
scp vflo-offline-bundle.tar.gz root@192.168.2.22:/opt/

# 内网服务器
cd /opt && tar xzf vflo-offline-bundle.tar.gz
bash vflo-offline/offline-install.sh install
bash vflo-offline/offline-install.sh verify
```

## 四、装完后部署应用

```bash
cd /opt/vflo-smart-office
cp .env.deploy.example .env   # 填密钥；PG_DATA=/data/pg
docker compose up -d
curl http://127.0.0.1:8000/api/health
```

## 五、注意

- 脚本不写入任何服务器口令 / API Key
- 系统盘 RAID1；数据盘挂 `/data` 后再跑生产
- `deploy.resources` 配额见 `docker-compose.yml`（合计约 24C / 73GB 上限）
- v1.2 起 `requirements.txt` 新增智能对话模块的附件解析依赖：`pypdf`、`python-docx`、`openpyxl`。
  应用镜像必须在【联网机】重新 `docker compose build` 后再 `docker save` 导出
  （pip 在构建期联网安装，内网服务器无需也不能在线 pip）
